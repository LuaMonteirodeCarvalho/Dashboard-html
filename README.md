# Dashboard HTML

Dashboard interativo desenvolvido com HTML, CSS e JavaScript para auxiliar na organização do dia a dia de forma prática, visual e personalizada.

Este projeto foi criado com apoio do Antigravity e faz parte das atividades práticas da PrograMaria.

## ✨ Funcionalidades

- 📰 Exibição das principais notícias do dia (fonte CBN)
- 🌤️ Previsão do tempo em tempo real
- 🕒 Data e hora atualizadas dinamicamente
- ☀️ Saudação automática:
  - Bom dia
  - Boa tarde
  - Boa noite
- 😊 Seleção de humor/emocional do dia
- 💬 Frases motivacionais personalizadas conforme o humor selecionado
- 🎵 Exibição de músicas relacionadas ao humor escolhido
- 📧 Exibição de e-mails não lidos
- 📅 Exibição de compromissos do dia
- 🔐 Login com conta Google
- 🎨 Interface com visual dark/neon
- 📱 Layout responsivo
